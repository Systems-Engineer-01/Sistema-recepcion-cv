# SIRE-CV — Frontend Web App

Aplicación web desarrollada en **React 19 + Vite + TypeScript** para la plataforma de Recepción Electrónica de CV.

## 🚀 Requisitos Previos

- Node.js >= 18.0.0
- npm >= 9.0.0

## 📦 Instalación

```bash
cd frontend
npm install
```

## 🛠️ Modos de Ejecución

### Desarrollo

Inicia el servidor de desarrollo Vite:

```bash
npm run dev
```

La aplicación estará disponible en `http://localhost:3000`. Conecta mediante proxy con el backend local (`http://localhost:4000`).

### Compilación para Producción

```bash
npm run build
```

### Vista previa del build

```bash
npm run preview
```

## 🎨 Diseño y Estética (Sprint 0)

- **UI Framework**: React + Vite + Vanilla CSS con variables de diseño.
- **Aesthetic**: Interfaz oscura en tonos Slate/Navy con efecto *glassmorphism*, tipografía *Outfit & Inter*, e iconografía SVG con `lucide-react`.
- **Accesibilidad**: Etiquetas HTML semánticas y campos con soporte de atributos de formulario.
